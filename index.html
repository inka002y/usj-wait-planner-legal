提供内容

本アプリは待ち時間、運営状況、営業時間、履歴の集計と来園プランの提案を提供します。ユニバーサル・スタジオ・ジャパンおよび関連企業が提供・承認する公式アプリではありません。名称・商標は各権利者に帰属します。入場券、整理券、エクスプレス・パスの販売・発行や優先入場は行いません。

外部情報と予測

待ち時間等には Queue-Times.com および ThemeParks.wiki を使用します。地図はiOSではAppleマップ、Web版ではOpenStreetMapを利用します。各提供元の権利・利用条件が適用されます。

情報は遅延・欠損することがあります。提案は時間帯別の履歴と推定徒歩時間を使った数理モデルに基づく目安で、実際の最短ルート、入場・乗車、待ち時間短縮や節約を保証しません。履歴不足の枠は目安値で補います。今後の運休・混雑や整理券の取得可否を保証するものでもありません。

身長・年齢等の利用資格は自動判定しません。食事やショー等の時刻は利用者が入力する予定です。整理券・受付終了・通行可否・営業時間等は公式案内と現地表示を優先してください。当日の計画変更は開園状況や残り時間によって利用できない場合があります。歩行中の画面操作を避け、安全な場所でご利用ください。

不正アクセス、過度な負荷、運営の妨害、権利侵害、外部データの無断転載・再配布を禁止します。提供元の停止や保守等により機能を変更・停止することがあります。重要な規約変更は適用日とともに本ページ等で周知します。

端末内で扱う情報

会員登録はありません。プランを端末内で生成し、プラン名、食事・休憩・ショー等の予定、当日の体験済み・見送り等の進捗を含む保存プラン一式はサーバーへ送信しません。これらと表示設定、履歴キャッシュは端末内に保存します。一方、待ち時間履歴を調べるため、選択した施設のID、参照期間、平日または土日祝の区分をSupabaseに送信します。

来園日は端末内で該当日の営業情報を選び、曜日・祝日の区分を判定するために使用します。現行の営業時間取得ではパーク全体の日程を取得し、来園日そのものをAPIの照会パラメーターとして送信しません。

端末の位置情報権限は要求せず、GPSによる現在地は取得しません。出発地点の施設は利用者が選びます。広告SDK、広告識別子による追跡、利用分析SDK、生成AIサービスへの送信は行っていません。

通信先と利用目的

  • Queue-Times.com、ThemeParks.wiki：パークの待ち時間、運営状況、営業時間の取得。
  • Supabase：公開施設の待ち時間履歴・集計の配信。施設ID、参照期間、曜日区分等の照会情報を受信します。サーバー側の待ち時間DBは施設の観測データを扱い、利用者の保存プラン一式は保管しません。
  • Appleマップ（iOS）、OpenStreetMap（Web版）：表示している地図領域や施設の座標等をもとに園内地図を表示します。端末GPSの現在地を本アプリから送信するものではありません。
  • GitHub Pages：サポート・規約・本ポリシー等のページの配信。これらを開いたときに通信します。

通信時、接続先にはIPアドレス、リクエスト時刻、照会内容等の技術情報が伝わり、配信・障害対応・セキュリティのために記録される場合があります。外部ページや通信先には各社のプライバシー方針が適用されます。運営者はこれらを広告追跡や販売に利用しません。運営者が個人情報の処理を委託する場合は、本方針と同等以上の保護を求め、目的に必要な範囲で取り扱います。

保存期間と削除

保存プランとその進捗は、ホームの保存プランの削除操作で消去できます。履歴キャッシュは最大21日分・6000件までを読み込み・更新時に整理します。履歴キャッシュだけを設定から削除する機能は現在ありません。アプリを削除すると端末内データも削除されますが、OSのバックアップに含まれる場合は、OSの設定から別途管理してください。

サーバー側の施設待ち時間履歴はプラン提案・分析に使用します。利用者のプランが消去されても、この公開施設の観測履歴は削除対象になりません。外部提供元が保持する接続ログ等の保存・削除は各社の方針に従います。運営者が管理する照会ログや問い合わせ情報は、不具合対応・セキュリティ・法令遵守等のために必要な期間に限って保持し、不要になった場合は削除します。
